Temporal drift modeling prevents stale preference signals from dominating review generation.MethodSignatureDescriptionencode_sequence(history: list[dict]) → torch.TensorFull pipeline; returns weighted (768,) vector_sort_by_time(history) → list[dict]Sort ascending by timestamp_apply_attention(embeddings, positions) → tensorSelf-attention with sinusoidal position encoding_recency_decay(tensor, timestamps) → tensorMultiply by exp(−λ·Δt); λ default 0.001/dayNOTESASRec outputs a single (768,) tensor that is concatenated with the APG4RecSim profile string embedding before LLM prompt construction.
